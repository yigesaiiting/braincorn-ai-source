# Braincorn Knowledge OS

这个 vault 的工作方式：Obsidian 负责阅读、链接、图谱；Codex 负责整理、编译、重写、质检、检索。

正式 AI 执行规范请看 [[Meta/AI_README|AI_README]]。
正式总索引请看 [[Meta/Index|Index]]。

## 日常节奏

1. 把资料丢进 `Inbox/` 或 `Raw/`。
2. 使用 `Meta/Prompts/` 中的工作流 prompt 让 Codex 编译。
3. 在 Obsidian 中阅读 `Wiki/Index.md` 和各目录 Index。
4. 重要输出放入 `Outputs/`，关键判断放入 `Resolutions/`。

## 重要原则

- 人负责收集资料和提出问题。
- Codex 负责编译 wiki 和质检结构。
- `Raw/` 是原始层，默认不改。
- `Wiki/` 是可复用知识层。
- `Outputs/` 是阶段性报告层。
