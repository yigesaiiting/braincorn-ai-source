# 基于知识库回答问题

请基于本 vault 已有资料回答我的问题。

要求：
1. 优先阅读相关 `Wiki/` 索引，再进入具体页面。
2. 必要时读取 `Outputs/` 中的历史报告。
3. 只能引用 vault 中已有资料；没有资料的地方标记 `资料不足`。
4. 输出结论、依据、风险、下一步行动。
5. 如果产生了新判断，请沉淀到相关 `Wiki/` 或 `Resolutions/` 页面。
