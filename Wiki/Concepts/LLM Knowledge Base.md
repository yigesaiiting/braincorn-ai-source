# LLM Knowledge Base

## 一句话定义

LLM Knowledge Base 是一种把原始资料持续编译成可检索、可链接、可维护的 Markdown 知识库的工作方式。

## 核心内容

- 人负责收集资料、提问题、做判断。
- LLM 负责整理、归纳、重写、补链、质检。
- 原始资料与编译后知识要分层存放。
- 知识不是一次性生成，而是持续维护。

## 关键判断

- 关键不在“生成更多笔记”，而在“让知识可查询、可复用、可迭代”。
- 如果不能持续更新和追踪来源，这个知识库就会变成静态文档堆。

- 用 Markdown 统一承载原始资料、编译知识和输出结果。
- 先分层，再补链，再做索引。
