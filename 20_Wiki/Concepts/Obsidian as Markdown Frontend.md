# Obsidian as Markdown Frontend

## 一句话定义

Obsidian as Markdown Frontend 的意思是：把 Obsidian 当作一个本地 Markdown 知识库的阅读和导航界面，而不是单纯记笔记的软件。

## 核心内容

- Obsidian 负责阅读、链接、图谱和局部跳转。
- Markdown 负责统一格式，方便迁移和自动处理。
- LLM / Codex 负责批量维护内容、补链和整理结构。
- Git 负责版本控制和回滚保护。

## 关键判断

- 如果没有链接和索引，Obsidian 只是文档编辑器。
- 如果有清晰分层和双链，它就能变成知识操作系统的前端。
