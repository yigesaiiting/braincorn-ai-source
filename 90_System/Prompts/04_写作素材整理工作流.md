# 写作素材整理工作流

请整理 `10_Raw/Writing/` 中的文本素材。

任务：
1. 提炼我的写作偏好。
2. 总结高频隐喻系统。
3. 建立“冷感克制表达”写作规范。
4. 把可复用句式放入 `20_Wiki/Playbooks/`。
5. 把具体文章草稿放入 `50_Outputs/Essays/`。
6. 资料不足处标记 `需要验证` 或 `资料不足`。
